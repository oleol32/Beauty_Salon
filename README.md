# Дипломный проект «Салон красоты» курса «1С Разработчик»

Проект реализует автоматизацию бизнес процессов cалона красоты: запись клиентов к мастерам, учёт услуг и товаров, контроль остатков, формирование документов и отчётов, запись клиентов посредством мобильного приложения.

## Технологии и стек
 - Платформа: 1С:Предприятие 8.3. 
- Язык: встроенный язык 1С, язык запросов. 
- Отчётность: СКД. 
- БСП: базовые подсистемы (функциональность, пользователи, права и т. д.). 
- Интеграции: мобильная платформа 1С, обмен данными.

## Архитектура и ключевые решения
 - Внедрены необходимые подсистемы БСП с постановкой на поддержку поставщика и адаптацией кода
 - Разработан каркас метаданных: перечисления, справочники, документы, регистры накопления и сведений
 - Реализованы оперативные отчёты: Товары на складах, Продажи, Финансовый результат, Движение наличных денег
 - Настроен контроль отрицательных остатков с выводом сообщения пользователю через БСП
 - Разработана подсистема Бухгалтерский учёт: план видов характеристик, план счетов, регистр бухгалтерии
 - Создан Журнал хозяйственных операций и отчёт «Оборотно-сальдовая ведомость по счёту»
 - Реализована внешняя печатная форма «Товарная накладная» через механизм БСП
 - Разработана загрузка прайс-листа из Excel в регистр Цены номенклатуры
 - Создана мобильная конфигурация для записи клиентов с авторизацией и обменом данными
